# Tutorials

Owner: Engine with all teams contributing onboarding material.

Tutorials are learning and onboarding assets. They are not production runtime code. Group new material by topic rather than by individual contributor.

Recommended topics:

- audio fundamentals
- data collection and cleaning
- model training and benchmarking
- overlapping sound detection
- cloud and deployment onboarding
- HMI dashboard and IoT health display onboarding
- team contribution workflow

Generated notebook checkpoints should stay untracked.

Compatibility note: the target structure calls this area `tutorials`; on this Windows workspace it resolves to the existing `Tutorials` folder. New tutorials should link to target docs such as `docs/team-guides/` and `docs/architecture/` rather than hard-coding old prototype paths.
