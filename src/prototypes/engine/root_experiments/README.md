# Root experiment migration

Owner: Engine

Status: migrated prototype material

lived in the repository root. They are prototype and research assets, not part of
the `src/production` production runtime.

classifies loose root ML notebooks/scripts as Engine-owned experiment work.

Do not add new work to the repository root. Put future Engine experiments under a
technical topic folder in `src/prototypes/engine`, or create a clearer topic
folder before starting new work.
